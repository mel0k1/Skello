# Skello

[![CI](https://github.com/mel0k1/Skello/actions/workflows/ci.yml/badge.svg)](https://github.com/mel0k1/Skello/actions/workflows/ci.yml)

Skello - инструмент для прошивки Android-устройств и получения root-прав с графическим интерфейсом. Ядро на Rust общается с телефоном по протоколам adb и fastboot напрямую, интерфейс на Flutter собран на Material 3 Expressive.

Проект в ранней стадии: протокольные крейты уже работают с реальными форматами сообщений, интерфейс и мастера прошивки в разработке.

## Зачем

adb и fastboot работают из терминала: нужно помнить команды, держать открытым терминал и на каждом шаге проверять себя вручную. Ошибка в имени раздела или прошивка чужого образа легко превращает телефон в кирпич. Skello ведёт по шагам: показывает состояние устройства, перед опасной операцией объясняет, что произойдёт, и проверяет условия (заряд, разблокированный загрузчик, размер образа) до того, как отправить команду.

## Что уже есть

- crates/skello-adb: каркас бинарного протокола adb (заголовок amessage на 24 байта, константы команд из AOSP) и клиент adb-сервера на порту 5037 со тестами
- crates/skello-fastboot: строки команд fastboot (getvar, download, flash, erase, set_active, reboot-*) и разбор ответов OKAY / FAIL / INFO / TEXT / DATA
- app: Flutter-приложение с темой Material 3 Expressive, светлой и тёмной, и честным пустым состоянием экрана устройств
- CI на GitHub Actions: fmt, clippy, тесты Rust на Linux и Windows, analyze и тесты Flutter

Подробности протоколов и разбор исходников AOSP - в [ARCHITECTURE.md](ARCHITECTURE.md).

## План MVP

1. Список устройств из adb-сервера (host:devices) на главном экране
2. Карточка устройства: модель, версия Android, заряд, состояние загрузчика через getvar
3. Перезагрузка в bootloader, recovery и fastboot из меню устройства
4. Мастер разблокировки загрузчика с предупреждением о полном стирании данных
5. Прошивка отдельных образов (boot, recovery, vbmeta) с проверкой max-download-size
6. Root через Magisk: патч boot.img на стороне компьютера и прошивка патченного образа

Порядок не фиксирован и может поменяться после обсуждения сценариев.

## Безопасность

Разблокировка загрузчика стирает всё хранилище устройства. Прошивка неподходящего образа или сбой на середине пути могут оставить телефон неработающим. Skello будет показывать, что произойдёт перед каждым опасным шагом, но ответственность за операцию остаётся на том, кто нажал кнопку. Проверяйте, что образ собран именно для вашей модели.

## Разработка

Нужны Rust stable и Flutter stable (проверено на Flutter 3.50).

```sh
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings

cd app
flutter pub get
flutter analyze
flutter test
```

Для сборки desktop-приложения сгенерируйте платформенную обвязку один раз:

```sh
cd app
flutter create --platforms=linux,windows .
```
