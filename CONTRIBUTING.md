# Участие в разработке

## Сборка и проверки

Нужны Rust stable и Flutter stable. Перед коммитом прогоняйте:

```sh
cargo fmt --all
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace

cd app
flutter analyze
flutter test
```

CI гоняет то же самое на Linux и Windows, незелёный PR не вливаем.

## Правила кода

- В коде нет комментариев: ни строковых, ни документационных. Если кусок кода непонятен без пояснения - это сигнал переписать код, а не добавить текст
- Имена констант, команд и переменных берём из исходников AOSP и референсных проектов как есть
- Тексты интерфейса живут в app/lib/l10n/*.arb, на русском и английском одновременно; в коде строк пользователя нет
- Код, перенесённый из чужих проектов, попадает в NOTICE с указанием источника и лицензии

## Коммиты

- Автор коммитов - mel0k1
- Название короткое и по делу: «app i18n», «chipset notes», без воды
- Перед коммитом тексты (README, доки, ARB) проходят antislop-аудит: без канцелярита, без шаблонных оборотов, без лишних обещаний
